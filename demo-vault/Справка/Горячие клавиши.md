# Горячие клавиши

| Действие | Сочетание |
|:---|---:|
| Новая заметка | {{Ctrl+N}} |
| Быстрый переход | {{Ctrl+O}} или {{Ctrl+P}} |
| Поиск по всем заметкам | {{Ctrl+Shift+F}} |
| Редактор ⇄ просмотр | {{Ctrl+E}} |
| Режим «Сплит» | {{Ctrl+Shift+E}} |
| Граф связей | {{Ctrl+G}} |
| Ежедневная заметка | {{Ctrl+D}} |
| Сохранить | {{Ctrl+S}} |
| Закрыть вкладку заметки | {{Ctrl+W}} |
| Следующая заметка | {{Ctrl+Tab}} |
| Назад / вперёд | {{Alt+←}} / {{Alt+→}} |
| Переименовать заметку | {{F2}} |
| Масштаб | {{Ctrl+=}} / {{Ctrl+-}} / {{Ctrl+0}} |
| Быстрая смена темы | {{Ctrl+`}} |
| Найти действие | {{Ctrl+Shift+A}} |
| Настройки | {{Ctrl+Alt+S}} |

## В редакторе

| Действие | Сочетание |
|:---|---:|
| **Жирный** | {{Ctrl+B}} |
| *Курсив* | {{Ctrl+I}} |
| `[[Ссылка]]` | {{Ctrl+K}} |
| ~~Зачёркнутый~~ | {{Ctrl+Shift+X}} |
| ==Выделение== | {{Ctrl+Shift+H}} |
| `Код` | {{Ctrl+Shift+C}} |
| Развернуть сокращение, следующее поле | {{Tab}} |
| Подсказки | {{Ctrl+Space}} |

Нажми {{Enter}} в конце пункта списка, и следующий маркер появится сам. На пустом пункте {{Enter}} завершает список.

Сокращения вроде `t3x4` или `-*3` и подсказки в ссылках описаны в заметке [[Сокращения и подсказки]].

Любое сочетание можно поменять: **Файл → Настройки → Горячие клавиши**. Там же видно, не занято ли оно другим действием.

> [!tip] Свои клавиши в заметках
> Пиши `{{Ctrl+S}}` — получится {{Ctrl+S}}. Или через HTML: `<kbd>Ctrl</kbd>`.
