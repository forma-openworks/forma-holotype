# Сокращения и подсказки

Редактор помогает писать быстрее, как IDE. **Подсказки** появляются сами, пока ты набираешь ссылку, тег или язык блока кода. **Сокращения** в духе Emmet превращаются в готовую разметку по {{Tab}}.

## Подсказки

| Начни писать | Что подскажет |
|:---|:---|
| `[[` | заметки хранилища: поиск по имени и пути, буквы можно пропускать |
| `[[Заметка#` | разделы этой заметки, а `[[#` — разделы текущей |
| `![[` | картинки и файлы с превью, а ещё заметки для встраивания |
| `![подпись](` и `[текст](` | пути к картинкам, файлам и заметкам |
| `#те` | теги, которые уже есть в хранилище |
| `> [!` | типы плашек |
| ```` ```ru ```` | языки блока кода; незакрытый блок закроется сам |
| `` `код`{gr `` | цвета и `badge` для атрибутов |

Стрелки {{↑}} и {{↓}} выбирают вариант, {{Enter}} или {{Tab}} вставляют, {{Esc}} закрывает. Можно щёлкнуть мышью. Вызвать подсказки вручную — {{Ctrl+Space}}.

## Сокращения

Напиши сокращение в пустой строке и нажми {{Tab}}. Пока пишешь, рядом появится превью того, что получится.

| Сокращение | Что получится |
|:---|:---|
| `h2{Заголовок}` | заголовок второго уровня |
| `-*3` | список из трёх пунктов |
| `ol*3` или `1.*3` | нумерованный список |
| `[]*3` или `todo*3` | список задач, `[x]` — выполненная задача |
| `t3x4` | таблица: 3 колонки, 4 строки |
| `t{Имя,Возраст}x2` | таблица с готовой шапкой |
| `!tip{Заголовок}` | плашка любого типа: `!note`, `!warning`, `!bug`…; `!faq-` — свёрнутая |
| `code:rust` или ```` ```rust ```` | блок кода; `code:rust{main.rs}` — с заголовком |
| `$$` или `math` | блок формулы |
| `flow`, `seq`, `pie`, `dot` | заготовки диаграмм, а ещё `mermaid:class` и `mermaid:state` |
| `fm` | свойства заметки с тегами |
| `q` | цитата |
| `lorem` или `lorem40` | текст-рыба |

Эти сокращения работают и посреди строки, сразу после слова:

| Сокращение | Что получится |
|:---|:---|
| `img` | `![[ ]]` и сразу список картинок |
| `link` | `[[ ]]` и список заметок |
| `kbd{Ctrl+S}` | клавиша {{Ctrl+S}} |
| `badge{новое}` | бейдж `новое`{badge} |
| `date` и `time` | сегодняшняя дата и текущее время |

### Как в Emmet

Сокращения собираются из частей:

- `>` — вложить: `-*2>-*3` даёт два пункта, в каждом по три вложенных;
- `+` — поставить рядом: `h2{План}+[]*3` — заголовок и три задачи под ним;
- `*N` — повторить N раз;
- `{текст}` — содержимое элемента;
- `$` — номер повтора: `-{Шаг $}*3` даёт «Шаг 1», «Шаг 2», «Шаг 3» (`$$` — с ведущим нулём, `$@5` — счёт с пяти);
- `( )` — группа: `(h3{Раздел $}+p{Текст})*2`.

> [!example] Попробуй
> В пустой строке напиши `h2{Покупки}+[]{Хлеб}+[]{Молоко}+[]*2` и нажми {{Tab}}.

## Места для ввода

После разворачивания курсор встаёт в первое место для ввода, а следующие обведены тонкими рамками. {{Tab}} переходит к следующему, {{Shift+Tab}} — к предыдущему, {{Esc}} заканчивает обход.

## Таблицы

В любой таблице {{Tab}} переходит к следующей ячейке и выделяет её текст, {{Shift+Tab}} — к предыдущей. В последней ячейке {{Tab}} добавляет новую строку.
