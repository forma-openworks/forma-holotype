# Rust — владение и заимствование

> [!abstract] Кратко
> У каждого значения ровно **один владелец**. Когда владелец выходит из области видимости, значение освобождается. Заимствовать можно либо много раз *неизменяемо*, либо один раз *изменяемо*.

## Три правила владения

1. У каждого значения есть владелец.
2. Владелец в каждый момент только один.
3. Когда владелец выходит из области видимости, значение удаляется (`drop`).

```rust
let s1 = String::from("привет");
let s2 = s1;            // владение перешло к s2
// println!("{s1}");    // ошибка: s1 больше не владеет строкой
println!("{s2}");
```

## Ссылки и заимствование

```rust
fn length(s: &String) -> usize {  // берём ссылку, не владение
    s.len()
}

fn push_world(s: &mut String) {   // изменяемая ссылка
    s.push_str(", мир");
}
```

> [!warning] Правило заимствования
> В один момент времени может быть **либо** любое число `&T`, **либо** ровно одна `&mut T`. Так компилятор исключает гонки данных.

## Время жизни

Аннотации времён жизни не меняют, сколько живут значения. Они только описывают связи между ссылками:

```rust
fn longest<'a>(x: &'a str, y: &'a str) -> &'a str {
    if x.len() > y.len() { x } else { y }
}
```
